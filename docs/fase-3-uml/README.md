# Fase 3 — Diagramas UML

**Entregable:** Diagramas UML modelados a partir de los requerimientos de la fase 2.

## Obligatorios

| Carpeta | Diagrama | Qué debe mostrar |
| ------- | -------- | ---------------- |
| `diagramas/casos-de-uso/` | Casos de uso | Actores y funcionalidades del sistema |
| `diagramas/clases/` | Clases | Entidades, atributos, métodos y relaciones |
| `diagramas/secuencia/` | Secuencia | Flujos clave: registro, compra, cambio de estado de pedido |
| `diagramas/actividades/` | Actividades | Proceso de compra y gestión de pedidos |

## Opcionales

En `diagramas/complementarios/`, según lo requiera el proyecto: estados, componentes, despliegue.

## Convención

Cada diagrama se sube **exportado en `.png`** y además con su **archivo fuente editable**
(por ejemplo `.drawio`, `.puml` o `.mdj`), con el mismo nombre base.
